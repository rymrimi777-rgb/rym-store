## The idea

RYM Store is a personal app store. One author, one catalogue: no marketplace, no developer sign-ups, no third-party publishing. Everything in it is made by Rym.

It is an official extension of my portfolio. It shares the same visual identity, but lives as its own independent site with its own pages and navigation.

### Principles

- **Real products only.** Nothing is shown as available before it is, and there are no fake download links.
- **Direct downloads.** Only the options that are actually configured appear on a product page.
- **Private management.** Products, versions and changelogs are managed by me, never exposed publicly.
- **Free to run.** Built on free services only.

## How it works, in short

A static site on Cloudflare Pages. The catalogue is a simple JSON file, edited through a private admin panel. App binaries are published as GitHub Releases.
